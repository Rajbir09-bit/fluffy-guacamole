

🎵 Spotify Clone
A fully responsive Spotify-inspired music player built using **HTML, CSS, and JavaScript**.
This project recreates the core frontend experience of Spotify with music playback, interactive controls, playlists, and a modern UI — all without using a backend.

🚀 Live Features
🎧 Play / Pause songs
⏭️ Next & Previous controls
📀 Interactive music playlist
📱 Responsive design
🎨 Spotify-inspired interface
📊 Progress bar & seek functionality
⚡ Smooth UI interactions using Vanilla JavaScript

---

🛠️ Built With

* HTML5
* CSS3
* JavaScript
